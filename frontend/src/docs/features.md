# Campus Blink Platform Features

Campus Blink is a comprehensive, student-centric web application designed to simplify campus life. Below is an overview of the core features and modules available on the platform.

## 1. Landing Page (`/`)
*   **Hero Section**: A high-impact, animated value proposition with dynamic text loading.
*   **Features Grid**: 3D interactive bento-box style cards highlighting core offerings.
*   **Interactive Ticker**: Infinite scrolling marquee of campus vibes and keywords.
*   **Student Dashboard CTA**: Direct pipeline to login or dashboard access.

## 2. Student Dashboard (`/student/home`)
*   **Overview Hub**: Personalized greeting ("Good morning, [Name]") linked to the authenticated user.
*   **Quick Metrics**: Live statistics on Reputation and notification alerts.
*   **Module Launcher**: 4 animated quick-access cards to instantly navigate to Buy/Sell, Canteen, Print Shop, or Community.
*   **Recent Activity**: A timeline of the student's recent interactions (e.g., "Order #302: Ready", "Sold: Physics Textbook").
*   **Quick Actions**: Shortcuts to commonly used actions like posting a notice or listing an item.

## 3. Canteen Pre-ordering (`/student/canteen`)
*   **Canteen Selection Grid**: Initial view allowing students to select from specific campus vendors (e.g., Nescafe, Main Canteen, Laziz Pizza, Southy Indian).
*   **Live Menu**: Categorized, searchable menu items displaying price, veg/non-veg tags, and live availability.
*   **Interactive Cart**: Slide-out sidebar to manage quantities, calculate totals, and place orders.
*   **Order History**: A dedicated tab allowing students to filter past orders by date ranges and view expenses.

## 4. Buy & Sell Marketplace (`/student/buy-sell`)
*   **Dynamic Listings**: A masonry grid of items for sale by other students.
*   **Category Filtering**: Quick pills to sort by Stationaries, Tech, Books, and Others.
*   **Visual Cards**: Image-forward listing cards highlighting price, condition, seller, and time posted.

## 5. Print Shop Integration (`/student/print`)
*   **Smart Layout**: A split-screen interface mimicking modern quick-commerce UI (e.g., Blinkit).
*   **Drag & Drop Upload**: Interactive zone for dropping PDFs or Word documents. 
*   **Print Configuration**: Precise settings for color mode (B&W vs. Color) and layout (Single/Double Sided) using custom geometric toggle switches.
*   **Live Cost Calculation**: Dynamic sticky banner updating the final print cost based on page counts and parameter selections.
*   **Checkout**: Proceed to print directly to the nearest campus vendor.

## 6. Community Feed & Notices (`/student/community`)
*   **Twitter/X Style Forums**: A chronological feed of student thoughts, questions, and announcements.
*   **Interaction Layer**: Mock capabilities for liking, replying, and resharing content within the student network.

## 7. User Profiles (`/student/profile`)
*   **Dynamic Identity**: A highly customizable social profile consisting of a Cover Photo and Profile Picture. 
*   **Advanced Editor**: An interactive "Edit Profile" modal. Features include CSS slider-based Avatar cropping/zooming, banner image upload simulation, and editable fields for Name, Username, Bio, Location, and Website.
*   **User Statistics**: Tracking for Followers, Following, and Reputation.
*   **Feed Tabs**: Dedicated sections for the user's specific Posts, Replies, and Likes.

## 8. General & Legal
*   **About Us (`/about`)**: Company mission and developer acknowledgements.
*   **Contact (`/contact`)**: Form inquiries securely directed to active support channels.
*   **Terms & Privacy (`/terms`, `/privacy`)**: Standardized legal agreements and data usage policies.
